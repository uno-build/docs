## Listen for node events

Use `node.on()` to register a listener.

```js
panel.on('pointerover', (event) => {
  panel.style('opacity', '0.5')
  ui.update()
})
panel.on('pointerout', (event) => {
  panel.style('opacity', '1')
  ui.update()
})
```

Every node `event` includes:

- `target`: the node where the event originated.
- `current_target`: the node whose listener is currently running.
- `source_event`: the original browser event.
- `stopPropagation()`: stops the event from bubbling through the `uno/ui` node tree.

## Remove node listeners

To remove a node listener while the node is still active, pass the same function to `node.off()`:

```js
function onPointerOver() {
  console.log('panel has been hovered')
}
panel.on('pointerover', onPointerOver)
panel.off('pointerover', onPointerOver)
```
